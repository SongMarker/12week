# 촌수 계산기

문제 링크  
__https://www.acmicpc.net/problem/2644__

분류  
그래프 탐색 (BFS)

설명  
두 사람 a, b 사이의 촌수를 BFS로 탐색하는 문제.  
부모-자식 관계를 양방향 인접 리스트로 구성한 뒤,  
a에서 출발해 b까지의 최단 거리를 구하면 그게 곧 촌수.  
연결되지 않은 경우 -1 출력.

시행착오 / 어려운 점  
그래프를 단방향으로만 연결했다가 오답 → 부모-자식은 서로 1촌이므로 양방향으로 연결해야 함  
visited 배열 없이 구현했다가 무한루프 → 방문 체크를 큐에 넣기 전에 해야 중복 방문 방지됨
